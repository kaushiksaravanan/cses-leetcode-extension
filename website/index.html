🔒 Privacy first

Your code never leaves your browser except to CSES — where it already goes when you submit normally.

What the extension accesses

  • ✅ host_permissions: https://cses.fi/* — Required to run the editor on CSES pages. No other sites are ever accessed.
  • ✅ No cookies permission — Your session cookie is sent automatically by the browser. The extension never reads it.
  • ✅ No storage permission — Drafts and language preference are saved with localStorage (in your browser, on your device). They never leave your machine.
  • ✅ No third-party servers — All code is sent directly to cses.fi, same as a normal form submission.

Frequently asked questions

Quick answers to common questions about the extension.

Does this extension collect my data?
No. The extension has zero analytics, zero tracking, and zero external connections. Your code is sent directly to cses.fi — the same server you already use. No data is stored or transmitted anywhere else. See the privacy policy for full details.
Do I need a CSES account?
Yes. You need a free CSES account to submit solutions. The extension uses your existing browser session — just log into CSES normally and the extension works automatically.
What keyboard shortcuts are supported?
Ctrl+Enter (or Cmd+Enter on Mac) submits your solution. Tab inserts 4 spaces so you can indent without the cursor jumping out of the editor.
Is my code saved if I refresh the page?
Yes. Your draft is saved locally (per problem) as you type. If you refresh or navigate away, it's restored when you return. The draft is automatically removed once your solution is accepted.
What languages are supported?
C++, C, Java, Python 3, and JavaScript (Node.js). The language selector appears above the code editor on every problem page, and your last choice is remembered.
Will this extension slow down CSES pages?
No. The extension is lightweight (~8 KB of JavaScript) and only activates on CSES problem set and task pages. It has no impact on other websites.
How do I update the extension?
Since this is loaded as an unpacked extension, you'll need to download the latest ZIP, extract it over your existing folder, and reload the extension at chrome://extensions (click the refresh icon on the extension card).
Is this affiliated with CSES or Chrome?
No. This is an independent, free project built by a student for personal learning and education. It is not affiliated with, or endorsed by, CSES, the University of Helsinki, LeetCode, or Google.
