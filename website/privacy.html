Privacy Policy

Last updated: July 28, 2026

Overview

CSES LeetCode Interface ("the extension") is a free browser extension created by a student for personal learning and education. It provides a code editor and submission interface for cses.fi. This policy explains what data the extension accesses and how it is handled.

Independent project: This extension is not affiliated with, or endorsed by, CSES, the University of Helsinki, LeetCode, or Google. It is distributed free of charge for educational purposes.

Data Collection

The extension does not collect, store, or transmit any personal data. Specifically:

  • No analytics: The extension contains no analytics SDKs, trackers, or telemetry of any kind.
  • No external servers: All network requests are made exclusively to cses.fi — the same server you interact with when using CSES normally.
  • No cookies read: The extension uses host_permissions only. Your CSES session cookie is sent automatically by the browser on same-origin requests; the extension never reads, modifies, or transmits it outside of cses.fi.
  • Local drafts only: To protect your work, the extension stores your in-progress code (drafts) and your last-selected language locally in your browser using localStorage. This data never leaves your device. Drafts are automatically cleared when a submission is ACCEPTED. Nothing is sent to any server except when you click Submit.

Data Transmitted

When you click Submit in the editor, the following data is sent to cses.fi/course/send.php:

  • Source code — the code you wrote in the editor
  • Language selection — e.g., C++, Python, Java
  • Task ID — the problem you are submitting to
  • CSRF token — a security token fetched from CSES' own submit page

This is exactly the same data that would be sent if you manually uploaded a file through CSES' web form. No additional data is included or appended.

Third-Party Services

The extension does not use any third-party services, APIs, CDNs, or external resources. It operates entirely within the context of cses.fi.

Children's Privacy

The extension does not knowingly collect any personal information from children under the age of 13. Since no data is collected at all, no special protections are required beyond the standard policy described here.

Changes to This Policy

If this policy changes, the "Last updated" date at the top will be revised. No other notification will be provided. Continued use of the extension after changes constitutes acceptance of the updated policy.

Contact

For questions about this privacy policy, open an issue on the GitHub repository.
